# Source Robotics Discussions

This repository holds the discussions of the Source Robotics organisation:
**[github.com/orgs/Source-Robotics/discussions](https://github.com/orgs/Source-Robotics/discussions)**. Ask questions,
show what you built and share ideas there, for PAROL6, the SSG-48 and MSG grippers, and the STEPFOC and Spectral
Micro drivers.

| You want to | Go to |
|---|---|
| Build, set up or program a product | the manuals at [docs.source-robotics.com](https://docs.source-robotics.com/) |
| Ask a question | [Q&A](https://github.com/orgs/Source-Robotics/discussions/categories/q-a) |
| Show your build or project | [Show and tell](https://github.com/orgs/Source-Robotics/discussions/categories/show-and-tell) |
| Suggest an idea | [Ideas](https://github.com/orgs/Source-Robotics/discussions/categories/ideas) |
| Report a bug in a design, the firmware or the software | the Issues of that product's repository |
| Chat with the community | [Discord](https://discord.com/invite/prjUvjmGpZ) |
| Ask about an order, shipping or a return | [source-robotics.com/pages/contact](https://source-robotics.com/pages/contact) |

Please search before you ask; mark the answer that solved your question, so the next person finds it. Everyone
here follows the [Code of Conduct](https://github.com/Source-Robotics/.github/blob/main/CODE_OF_CONDUCT.md).
